# Infrastructure & Deployments (IaC)

This directory houses the infrastructure-as-code files, deployment charts, container specifications, and continuous integration/delivery configurations.

## 📁 Scope
*   `docker/`: Local test containers for databases, caching servers, and local execution runtimes.
*   `k8s/`: Kubernetes deployment manifests, routing ingress rules, and scale configurations.
*   `pipelines/`: CI/CD pipelines (GitHub Actions, GitLab CI/CD) and automated testing hooks.
