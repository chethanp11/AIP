# Workflows: Reporting Suite

This directory contains the stateful workflows that compose the reporting capabilities of AIP, producing automated narratives, scheduled briefs, and high-fidelity output compilations.

## 📋 Standard Workflows
- **Monthly Performance Executive Briefing**: Assembles key metrics, runs trend analysis, and writes a narrative overview.
- **Operational Daily Summaries**: Creates a compact snapshot of daily operational metrics for Slack and email delivery.
- **Board Slide-Deck Preparation**: Compiles tables and charts grounded in the KMS into clean, downloadable PowerPoint/PDF files.

## ⚙️ Standard Capabilities Composed
- `capabilities/knowledge_retrieval`
- `capabilities/metric_interpretation`
- `capabilities/narrative_generation`
- `capabilities/visualization`
