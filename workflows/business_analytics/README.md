# Workflows: Business Analytics Suite

This directory contains the stateful workflows that enable dynamic metric exploration, ad-hoc slicing and dicing, and natural language querying over governed schemas.

## 📋 Standard Workflows
- **Interactive Metric Exploration Canvas**: Provides the stateful backing for the visual metric tree UI.
- **Natural Language Query (NLQ) Assistant**: Handles natural language queries, maps them to database schemas, and displays results.
- **Automated Root-Cause Diagnostic Pipeline**: Responds to analyst queries by executing variance contribution scans over specified intervals.

## ⚙️ Standard Capabilities Composed
- `capabilities/knowledge_retrieval`
- `capabilities/context_management`
- `capabilities/metric_interpretation`
- `capabilities/visualization`
